# Soha v0.1.15

This release adds repository installation and version discovery to the plugin marketplace.

- Install manifest-only plugins from a public GitHub repository, an exact Release, or an explicit branch or tag. Repository URLs use the latest stable Release when one exists.
- Browse GitHub Release history in the marketplace and see available same-source upgrades on the installed plugins page. Review and confirm an upgrade before Soha writes it.
- Use the repository index at `marketplace.opensoha.com` by default. The versioned compatibility catalog and its historical snapshots remain available. Administrators can register public HTTPS catalogs, and one unavailable source leaves healthy catalogs browsable.

## 中文

本版为插件市场加入 GitHub 仓库直装和版本发现。

- 支持公共 GitHub 仓库、指定 Release 和明确的分支或标签。仓库裸地址默认用最新稳定 Release，无稳定 Release 时需要选择分支。
- 市场详情显示 Release 历史，已安装列表提示同源更新。用户预览并确认后，Soha 才会升级。
- 默认读取 `marketplace.opensoha.com` 的仓库索引。旧目录和历史快照继续可读。管理员可接入公开 HTTPS 目录，故障源与健康目录独立展示。
