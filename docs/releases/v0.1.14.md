# Soha v0.1.14 · Reliability update

Soha v0.1.14 improves the reliability of browser sessions, knowledge search, and application delivery in the self-hosted console.

## Highlights

- **Browser sessions.** Late authentication responses no longer overwrite a newer sign-in. Sign-out targets the current session. A stalled browser handoff times out so a later sign-in can proceed.
- **Knowledge search.** Searches apply each knowledge base's retrieval settings. When a result matches both keyword and vector search, its original keyword rank contributes to the combined score.
- **Application delivery.** Build and release records are linked before a runner can claim the execution. Retrying resets the execution and its related records together, preventing late callbacks from an earlier attempt from overwriting the new result.
- **Kubernetes console.** Resource lists update more efficiently, and operations give more consistent progress and result feedback across resource views.

## Install and upgrade

- Container image `ghcr.io/opensoha/soha:v0.1.14` for Linux amd64 and arm64.
- For Linux amd64, download the standalone binary or installation archive from Assets. Verify the corresponding SHA-256 checksum before installing. The release manifest records the source revision and artifact checksums.
- Back up PostgreSQL before upgrading and check your configuration against the deployment guide. Core ships with the Web console built from the same source revision.

## 简体中文

Soha v0.1.14 改善了自托管控制台的浏览器会话、知识检索和应用交付稳定性。

- **浏览器会话。** 晚到的认证响应不会覆盖新会话。注销作用于当前会话。浏览器交接卡住时会超时，后续登录可以继续。
- **知识检索。** 查询遵循各知识库的检索设置。结果同时命中关键词和向量检索时，原始关键词排名会计入综合评分。
- **应用交付。** Runner 领取执行任务前，系统会完成构建与发布记录的关联。重试同时重置执行和关联记录，旧尝试的迟到回调不会覆盖新结果。
- **Kubernetes 控制台。** 资源列表更新更高效，各资源页面的操作进度和结果反馈更一致。

### 安装与升级

- 容器镜像为 `ghcr.io/opensoha/soha:v0.1.14`，支持 Linux amd64 和 arm64。
- Linux amd64 可从 Assets 下载独立二进制或安装包。安装前验证对应的 SHA-256 校验和。版本清单记录源码提交和产物校验和。
- 升级前请备份 PostgreSQL，并参照部署指南检查配置。Core 内置同一源码版本构建的 Web 控制台。
