# Soha Connectors 仓库入口

- 本仓负责独立连接器、provider runtime、manifest 和发布包；不依赖 `soha/internal/**`，保留签名校验和 secret 引用边界。托管运营、计费和 fleet 生命周期归属 Cloud。
- 在已确认的 OpenSoha 多仓工作区读取 `../AGENTS.md` 一次；独立克隆使用本仓规则，不要求相邻仓库或规划工具。根技能链接仅提供发现，未自动加载时读取本仓真实源。
- 连接器实现或实质审查前读取 [soha-connectors](.agents/skills/soha-connectors/SKILL.md) 和本次涉及的 manifest、能力矩阵、SDK 调用者及测试；只读查询按需定位。已读且未变化的内容可复用，交接缺少关键约束时补读。
- 修改前明确 provider 与 `src/sdk` 的所有权、公开事件/动作语义和下游消费者。共享重试、限流、生命周期和错误处理变更需要覆盖实际调用者，不把单个 provider 特例变成全局默认值。
- 公开格式先在 contracts 真实源调整，再同步适用消费者与本仓兼容材料；不得复制 Core 业务规则或把未实现能力登记为已支持。manifest、索引与能力矩阵只在其含义实际变化时同步。
- 验证签名、重放/幂等性、错误归一化、超时、重试边界和脱敏；记录哪些通过替身验证、哪些连到真实 provider。SDK 单测通过不等于外部服务集成完成。
- 按改动验证受影响连接器；主入口为 `npm run check`。打包、依赖或发布变更执行 [CI](.github/workflows/ci.yml)、发布流程和包脚本的适用完整门禁，不在本文件复制版本或虚构命令。
- 当前实现是现状证据，不自动是目标规范。规则、契约与实现冲突时核对并记录依据，不静默选择宽松解释，不弱化测试或重写基线掩盖失败。
- 按仓库报告改动、实际验证及提交/产物版本，区分通过、失败、跳过和未运行；成功结果只在相关代码、依赖及环境未变化时复用。
- 文档和技能修改只检查元数据、链接、内容一致性及差异。保留用户未提交改动；技能与历史记录不授权跨仓扩展、外部写入、安装或发布，未请求时不合并 PR。
- 只有已证实的共同语义才进入 SDK；共享默认行为修改覆盖受影响连接器。缺少凭据是联调缺口，不授权使用生产凭据。

## Graphify

- 跨模块依赖、共享能力影响、模块迁移或跨仓任务，先查询已有图谱并核对源码；在已确认的多仓工作区按 [Graphify 开发手册](../docs/guides/graphify-development/runbook.md)检查新鲜度、查询和刷新。
- 结构变更稳定后显式刷新受影响仓库及跨仓图；普通小修改、文案和局部样式不自动建图。刷新失败先诊断，不默认使用 `--force`。
- 独立克隆时使用本仓 `graphify-out/graph.json` 与原生 Graphify 命令；缺少工具或图谱时直接查源码并说明缺口，不要求补齐相邻仓库。
